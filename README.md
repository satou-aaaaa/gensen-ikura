# 源泉徴収いくら？（gensen-ikura）

原稿料・講演料・弁護士や税理士の報酬を払う場面（消費税を分けて書いた請求書・本人に渡した旅費・懸賞の賞金 など）を読んで、源泉徴収する税額を当てる1日5問の学習ゲーム。正解したら「どの計算？」（×10.21％・100万円を超える・しなくてよい）も選ぶ。

遊ぶ: <https://satou-aaaaa.github.io/gensen-ikura/>

- 答えは、国税庁タックスアンサーの計算（100万円以下は×10.21％、100万円を超えると(額−100万円)×20.42％＋102,100円。1円未満は切り捨て）と、対象の額の決まりから出しています（［令和8年4月1日現在法令等］。2026-11-17 に読みました）。
  - No.2795 原稿料や講演料等を支払ったとき <https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2795.htm>
  - No.2798 弁護士や税理士等に支払う報酬・料金 <https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2798.htm>
  - No.2792 源泉徴収が必要な報酬・料金等とは <https://www.nta.go.jp/taxes/shiraberu/taxanswer/gensen/2792.htm>
- 払う相手はどれも居住者の個人です。法人への支払い・外交員やホステスなどほかの報酬・非居住者・納付の手続きは出しません。人と金額はつくりものです。
- このゲームは源泉徴収のしくみを知る練習です。税の相談の代わりではありません。実際の税額は、国税庁の資料や税務署で確かめてください。
